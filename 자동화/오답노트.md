# 쿠팡 우회 시도 오답노트

## [기록 날짜: 2026-04-08]

### 초기 상태 분석
- **문제점**: 셀레늄 기반 스크래핑 시 'Access Denied' (차단) 발생.
- **영향**: 상품명, 이미지 추출 실패 -> 소구점 모델 품질 저하.
- **목표**: 차단 없이 3개 상품의 정확한 상품명을 반환.

---

### 가설 1-1: curl_cffi 기반 직접 우회 시도
- **내용**: `curl_cffi(impersonate="chrome120")`을 사용하여 쿠팡 상품 페이지 직접 요청.
- **실행 결과**: 실패 (`Status 200`이나 Akamai Challenge 페이지 반환)
- **실패 원인/디버깅**: 
    - `debug_coupang.html` 확인 결과, Akamai의 자바스크립트 챌린지 페이지가 반환됨.
    - `curl_cffi`는 JS 엔진이 없어 해당 챌린지를 풀 수 없으며, 쿠키(`_abck` 등)가 생성되지 않아 접근 불가.

### 가설 2: seleniumbase UC(Undetected Chromedriver) 모드 적용
- **내용**: `Driver(uc=True)`를 사용하여 브라우저 기반으로 접근하여 Akamai 챌린지 해결.
- **실행 결과**: **성공 (우회 완료)**
- **증거**: `sb_test_coupang.png` 확인 결과, 'Access Denied' 대신 쿠팡의 정상적인 헤더/푸터가 포함된 '상품을 찾을 수 없습니다' 페이지가 표시됨. 즉, 보안 차단은 뚫림.
### 가설 3: 통합 우회 및 Threads-Coupang 연계 테스트 (v5)
- **내용**: `seleniumbase` UC 모드로 Threads 팝업 제거 -> 쿠팡 링크 추출 -> 쿠팡 Akamai 우회 -> 상품명 추출.
- **실행 결과**: **완전 성공 (3/3 패스)**
    1. **슬러시메이커**: `조물조물 슬러시메이커...` (일치)
    2. **랑콤 선크림**: `랑콤 톤업 선크림...` (일치)
    3. **치즈스틱**: `우일수산 하이즐 치즈스틱...` (일치)
- **핵심 성공 요인**:
    - **Akamai 우회**: `Driver(uc=True)` 환경에서 JS 챌린지를 브라우저가 자동 해결.
    - **Threads 추출**: `Keys.ESCAPE`를 활용한 팝업 해제와 정규식 보완으로 유효 링크 확보.
    - **상품 파싱**: `og:title` 폴백 및 상품명 정제 로직으로 엑셀 정답과 100% 매칭.
- **최종 조치**: 해당 로직을 `scraper.py`에 전면 반영 완료.
